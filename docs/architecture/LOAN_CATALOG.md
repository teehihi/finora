The public terms below were checked against official lender pages on 26 November 2026 (Vietnam time). These records are an educational snapshot, not a quote, endorsement, recommendation, a personalized rate, or a decision on eligibility. The catalog does not submit a loan application.

The authoritative dataset is `apps/api/src/catalog/loans.vn.json`. Public rows are separate from V2 synthetic pricing and its existing `/api/catalog` simulator. Reviewed here means the checked-in fields were manually matched to the cited official page; it does not imply lender confirmation of an individual offer. Data can become stale. Null stays null; a lending method is not inferred just from an interest basis; fees are not set to zero unless the aggregate is known explicitly. Completeness is a coverage count for ten fields: both amount bounds, both term bounds, a rate disclosure, schedule method, aggregate fee, insurance, prepayment conditions and eligibility. It is not a suitability score. A `searchPublicLoans` filter excludes contradictions with known amount/term bounds; a missing bound leaves eligibility unknown.

## Refresh and review

1. Open the lender's own public product page and, if applicable to the same product, the applicable tariff or offer document. If the source is inaccessible, not clearly applicable, unclear, or conflicts with a different promotion, leave the uncertain field empty. Do not bypass access restrictions; there is no crawler or automatic extraction job.
2. Save candidate records in the current JSON format, with stable IDs, both locale variants, field units, source title/URL/type, collection date and human review date. Mark only reviewed official records as `reviewed_public`. Any AI-assisted draft must remain outside the published dataset until a human independently verifies the terms. No AI or model output is accepted by an automated publishing endpoint.
3. Run `pnpm --filter @finora/contracts build` then `node apps/api/scripts/catalog-intake.mjs candidate.json`. The validator rejects non-HTTPS/unrecognized lender hosts, inconsistent date or bounds, duplicate IDs/normalized product identities/reused product-page URLs, and unreviewed rows. To add another official lender, first verify the domain and add it to the reviewed allowlist.
4. Apply the reviewed file locally with `node apps/api/scripts/catalog-intake.mjs candidate.json --publish-local`. Inspect the git diff to preserve prior versions and document changes. Run tests before committing. This does not deploy or mutate user data.

Authenticated endpoints: `GET /api/intelligence/catalog` and `GET /api/intelligence/catalog/:id`. Filters: `query`, `category`, `amount` (VND integer), `months`, and `limit`. The list is not ranked by affordability or cost; a term-only comparison cannot compare flat/declining, monthly/annual, differently conditioned, or incomplete rates as if equivalent. For cost calculations a user needs confirmed terms or explicitly states assumptions; the app does not promote advertised rates into approved rates or fees into zero.
