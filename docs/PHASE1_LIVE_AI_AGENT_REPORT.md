## Remaining limits and next steps

1. Finora streams progress, validated answer chunks and typed blocks over SSE **after** a bounded provider completion. Upstream model token streaming is not implemented; it would require a safe buffering and validation design before displaying model text.
2. Native iOS/Android safe areas, fonts, tap targets and cancellation were not run on a simulator or device. Owner UAT and native visual QA are still required before a release claim.
3. The qualitative narrative guard is conservative lexical filtering, not a formal guarantee of factual accuracy. Keep typed engine cards authoritative and expand adversarial evaluation before a hosted rollout.
4. Catalog values remain reviewed public data with dates and sources. Finora does not promise approval, invent fees or rates, apply to lenders, or connect to production banking data.
5. The user's Claude gateway accepts inference but does not expose model metadata for a definitive probe. OpenAI-compatible live inference needs a separately configured credential and smoke check if that provider will be deployed.

No production database, OTP, real contract or personal financial data was used for these tests. Chrome on Windows is the only tested UI platform in this report.
