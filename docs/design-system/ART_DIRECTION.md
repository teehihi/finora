# Art direction · Sổ tay tài chính

Finora is a personal loan decision and repayment companion, not a lender dashboard. Its atmosphere should be that of a well-kept financial notebook: a warm page, a clear figure, an honest note in the margin, and a calm next step.

- **Typography:** short Source Serif 4 headlines in Vietnamese, Instrument Serif in English, Geist in all forms, navigation, values and dense copy. Use tabular digits for comparison. In Vietnamese, prioritize natural line breaks and retain all accents.
- **Composition:** ivory is the default reading canvas. Forest anchors one subject, such as Home's monthly estimate or the simulator's result. Mint groups related content rather than decorating every row. Thin ledger rules separate evidence and assumptions. Deliberate whitespace should make the next action clearer.
- **Financial truth:** distinguish estimated, known, unknown and illustrative values with words. Never suggest approval, invent activity, or present a missing fee as 0 ₫. Present chart status in text too. Show the editable calculation before encouraging action.
- **Interaction:** mobile feels like a compact native tool with a quiet dock, large tap targets and full-width fields. Larger screens gain navigation and an optional supporting column, not empty lateral space or more cards. Treat AI as a destination with sources inside the conversation, not a separate purple visual language.
- **Identity:** retain the exact logo, palette family and icon source. The local paper-boat photograph gives public onboarding a single editorial metaphor; it is not used as background in task-heavy screens. Do not distort the logo or turn a reference board into a mascot asset.
- **Material and motion:** intentional matte surfaces, minimal borders, no decorative gradient or float; keep glass solely in functional native navigation. Use brief motion only for state and respect Reduce Motion.
- **Authentication:** keep the actionable form visually distinct from editorial brand copy. Explain what happens before the email code is requested. Offer provider buttons only when actually available. Keep password sign-in reachable without making it the primary route.

This direction was selected from three rendered Home/auth alternatives. See [design exploration](DESIGN_EXPLORATION.md), [brand guidance](BRAND_GUIDELINES.md) and [semantic tokens](DESIGN_TOKENS.md).
