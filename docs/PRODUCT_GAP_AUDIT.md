# FINORA product gap audit

**Starting point:** `main` at `a1b9030` (through PR #11), with the local network fix from `e6b7c9a` applied before the sprint. The latest completed baseline evidence for the installed loan center is [Finora CI](https://github.com/teehihi/finora/actions/runs/45829624601). This is an implementation inventory, not a claim that every feature was reverified in this sprint.

## Sprint priorities

1. Preserve a stable local baseline and make exact verification reproducible.
2. Improve Home, onboarding and repayment navigation without disrupting the approved dock.
3. Make one coherent borrowing/AI/contract/repayment journey; favor evidence and explicit assumptions over cosmetic controls.
4. Run mobile and desktop web journeys with synthetic data; report any missing native/runtime/credential verification separately.
