# Optional Google authentication assets

- `google-g.png` is the unmodified Google G asset from the [Sign in with Google branding guidelines](https://developers.google.com/identity/branding-guidelines), shown only in Google identity controls.
- `GoogleSansMedium-FinoraAuth.ttf` is a 500-weight subset of [Google Sans](https://github.com/google/fonts/tree/main/ofl/googlesans) for these buttons' Vietnamese and English labels. The accompanying OFL text applies.
